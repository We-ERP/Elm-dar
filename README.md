# المدار Elmadar — الموقع

## الملفات
- index.html — الصفحة الرئيسية وكل الأقسام
- css/style.css — التنسيقات المخصصة
- js/app.js — منطق الموقع (التنقل، المقاييس، الفلاتر، النماذج)
- assets/logo.png — شعار المدار

## النشر على GitHub Pages
1. ارفع كل محتويات هذا المجلد (وليس المجلد نفسه) على ريبو جديد.
2. Settings → Pages → Source: Deploy from a branch → main / root → Save.
3. الموقع هيكون متاح على: https://USERNAME.github.io/REPO/
